NeoForge 및 테스트 서버 모드팩 설치 가이드

Minecraft 26.1.2 · NeoForge 26.1.2.97 기준
Minecraft26.1.2 NeoForge26.1.2.97 Java25 대상 런처공식 Minecraft Launcher
핵심 요약
Java 25를 준비한 뒤 NeoForge installer에서 Install client를 실행합니다. 설치 후 Minecraft Launcher에 생성된 NeoForge 프로필로 게임을 한 번 실행한 다음, 모드팩의 required 폴더에 있는 모든 JAR를 mods 폴더에 넣습니다.
모드 버전만 업데이트된 경우
새 모드팩의 required 폴더에 있는 모든 JAR를 Minecraft의 mods 폴더에 그대로 붙여넣습니다. 단, 같은 모드의 이전 버전 JAR가 mods 폴더에 남아 있으면 안 됩니다. 새 버전을 붙여넣기 전에 이전 버전을 삭제하세요.

빠른 설치 순서

  1. Java 25 설치
  2. NeoForge 26.1.2.97 installer 다운로드
  3. Minecraft Launcher 완전히 종료
  4. NeoForge installer 실행 → Install client → Proceed
  5. Minecraft Launcher 실행
  6. 자동 생성된 NeoForge 프로필 선택
  7. NeoForge로 Minecraft를 한 번 실행한 뒤 종료
  8. 테스트 서버 모드팩 ZIP 다운로드 및 압축 해제
  9. required의 모든 JAR와 원하는 recommended JAR를 Minecraft의 mods 폴더로 복사
  10. NeoForge 프로필로 Minecraft 실행 후 서버 접속
주의
같은 모드의 이전 버전 JAR가 남아 있다면 삭제하세요.

1. Java 25 설치

Minecraft 26.1 계열의 NeoForge를 사용하려면 Java 25가 필요합니다.

Java 25가 이미 설치되어 있는지 확인하려면 Windows에서 명령 프롬프트 또는 PowerShell을 열고 다음 명령을 실행합니다.

java -version

출력의 버전 번호가 다음처럼 25로 시작하면 됩니다.

openjdk version "25..."
Java 명령어를 확인할 수 없는 경우
java 명령어를 찾을 수 없거나 인식할 수 없다는 메시지가 표시되면 아래 링크에서 Java 25 배포판을 설치하세요.
Eclipse Temurin 25 다운로드
설치 후 다시 java -version을 실행하여 확인합니다.

2. NeoForge 다운로드

NeoForge 공식 사이트에서 Minecraft 26.1.2용 NeoForge 26.1.2.97 installer를 다운로드합니다.

사용할 버전:

NeoForge 26.1.2.97

installer 파일 이름은 보통 다음과 같은 형태입니다.

neoforge-26.1.2.97-installer.jar
주의
이 테스트 서버 모드팩은 Minecraft 26.1.2 기준입니다. 다른 Minecraft 버전용 NeoForge를 설치하는 경우 서버 접속이 불가할 수 있습니다.

3. NeoForge 설치

  1. Minecraft Launcher를 완전히 종료합니다.
  2. 다운로드한 neoforge-26.1.2.97-installer.jar를 실행합니다.
  3. Install client를 선택합니다.
  4. Proceed를 눌러 설치합니다.
  5. 설치가 끝나면 Minecraft Launcher를 다시 실행합니다.

4. NeoForge로 Minecraft 한 번 실행

  1. Minecraft Launcher를 실행합니다.
  2. 자동 생성된 NeoForge 26.1.2.97 프로필을 선택합니다.
  3. Minecraft를 실행합니다.
  4. 메인 화면까지 정상적으로 진입한 뒤 게임을 종료합니다.

이 과정을 거치면 Minecraft의 Game Directory 안에 mods, config 등 필요한 폴더가 생성됩니다.

5. mods 폴더 위치

기본 Minecraft Game Directory를 사용하는 Windows 환경에서는 보통 다음 위치에 있습니다.

%APPDATA%\.minecraft\mods

실제 경로 예:

C:\Users\<사용자 이름>\AppData\Roaming\.minecraft\mods
가장 빠르게 여는 방법
파일 탐색기 주소창 또는 Win + R에 아래 내용을 입력하세요. 
%APPDATA%\.minecraft\mods

6. 테스트 서버 모드팩 다운로드

최신 테스트 서버 모드팩은 아래 주소에서 다운로드할 수 있습니다.

https://github.com/najaewon-modding/test-server-modpack/releases/latest/download/test-server-modpack.zip

다운로드한 test-server-modpack.zip의 압축을 풀면 다음 두 폴더가 있습니다.

test-server-modpack/ ├─ required/ └─ recommended/

7. Required / Recommended 모드 설치

required

테스트 서버 접속에 필요한 모드입니다. 모두 설치하세요.

required/
→ 안의 모든 .jar 파일을 mods 폴더로 복사

recommended

서버 접속에 필수는 아니지만 사용을 권장하는 선택 모드입니다.

recommended/
→ 원하는 .jar 파일만 mods 폴더로 복사

8. 설치 예시

압축을 푼 직후

test-server-modpack/ ├─ required/ │ ├─ njw_compass_bar-... │ ├─ njw_just_chat-... │ ├─ njw_just_dragon_eggs-... │ ├─ njw_just_end_portal-... │ ├─ njw_just_skills-... │ ├─ njw_just_tractor-... │ ├─ njw_librarian_negotiations-... │ └─ voicechat-neoforge-... └─ recommended/ ├─ njw_clean_shot-... └─ njw_just_volume_controller-...

설치 후 mods 폴더 예시

.minecraft/ └─ mods/ ├─ njw_compass_bar-... ├─ njw_just_chat-... ├─ njw_just_dragon_eggs-... ├─ njw_just_end_portal-... ├─ njw_just_skills-... ├─ njw_just_tractor-... ├─ njw_librarian_negotiations-... └─ voicechat-neoforge-...

추천 모드를 설치한 경우 해당 JAR들도 같은 mods 폴더 안에 함께 들어갑니다.

9. 모드팩 업데이트 방법

중요
새 버전을 설치할 때는 같은 모드의 이전 버전 JAR를 삭제해야 합니다. 이전 버전과 새 버전을 동시에 넣어 두면 duplicate mod 또는 버전 충돌 오류가 발생할 수 있습니다.

잘못된 예

mods/
├─ njw_just_skills-1.0.3-mc26.1.2.jar
└─ njw_just_skills-1.0.4-mc26.1.2.jar

올바른 예

mods/
└─ njw_just_skills-1.0.4-mc26.1.2.jar

업데이트가 공지되면 최신 모드팩 ZIP을 다시 다운로드한 뒤, 이전 버전 JAR를 제거하고 새 버전으로 교체하세요.

10. Minecraft 실행 및 서버 접속

  1. Minecraft Launcher를 실행합니다.
  2. NeoForge 26.1.2.97 프로필을 선택합니다.
  3. Minecraft를 실행합니다.
  4. 메인 화면까지 정상적으로 진입하는지 확인합니다.
  5. 멀티플레이를 선택합니다.
  6. 서버 추가를 선택한 뒤 테스트 서버 주소를 입력합니다.
  7. 추가한 테스트 서버를 선택하여 접속합니다.

11. 자주 발생하는 문제

NeoForge installer가 실행되지 않음

먼저 Java 25가 정상적으로 설치되었는지 확인합니다.

java -version

필요하면 installer를 직접 실행합니다.

java -jar neoforge-26.1.2.97-installer.jar

Minecraft가 실행 직후 종료됨

  • Java 버전이 25인지 확인
  • NeoForge 버전이 26.1.2.97인지 확인
  • 같은 모드의 이전 버전과 새 버전이 동시에 들어 있지 않은지 확인
  • 다른 Minecraft 버전용 모드가 섞여 있지 않은지 확인

서버 접속 시 mod mismatch 또는 missing mods 오류

  • 최신 모드팩 ZIP을 다시 다운로드
  • required 폴더의 모든 모드를 설치했는지 확인
  • 이전 버전 JAR가 남아 있지 않은지 확인

mods 폴더가 보이지 않음

  • NeoForge 프로필로 Minecraft를 한 번 실행
  • 실제로 사용 중인 Game Directory 위치 확인

recommended 모드를 꼭 설치해야 하나?

아닙니다. recommended는 선택 사항입니다. 서버 접속에는 required만 필요합니다.
